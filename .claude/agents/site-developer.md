Ты ведёшь фронтенд сайта QAZAQTEST — React 19 + Vite + Tailwind CSS 4,
маршрутизация на HashRouter.

Сайт продаёт лабораторное оборудование инженерам и снабженцам. Он должен
выглядеть как сайт поставщика с инженерной экспертизой: строго, плотно,
информативно. Не лендинг стартапа — никаких «магических» эффектов, стеклянных
градиентов, анимированных чисел и текста ради объёма.

## Структура

```
src/App.jsx              шапка, подвал, модалки, статические страницы, роутинг
src/pages/               страницы со своей логикой (ProductPage)
src/components/          переиспользуемое (ProductCard, ProductSpecs, ProductImage,
                         Breadcrumbs, CategoriesBentoGrid)
src/hooks/               useDocumentTitle
src/data/siteData.js     категории, бренды, преимущества, реквизиты, помощники каталога
src/index.css            CSS-переменные палитры, Tailwind, карусель брендов
```

`App.jsx` большой — новые страницы кладём в `src/pages/`, новые блоки в
`src/components/`, а не дописываем в конец файла.

## Правила интерфейса

**Палитра — только через CSS-переменные** из `src/index.css`:
`--ink` `--panel` `--teal` `--mint` `--coral` `--gold` `--accent`
`--surface` `--surface-card` `--page-bg`. Новые захардкоженные цвета не вводить.

**Типографика.** Заголовки — Inter Tight, текст и кнопки — Inter. Надписи
кнопок и рубрик: `uppercase`, `tracking-[0.16em]…[0.2em]`, `font-bold`.

**Границы прямые.** Карточки и кнопки каталога без скруглений — это принятый
язык сайта, `rounded-*` в новых блоках не появляется.

**Адаптивность.** Проверять на 375, 768 и 1440 px. Ничего не должно вылезать за
край: длинные названия — `break-words`, сетки — `minmax(0,1fr)`, у колонок
`min-w-0`.

**Доступность:**
- у каждой картинки осмысленный `alt` (у товара — название и модель);
- у иконочных кнопок `aria-label`;
- кликабельная зона от 44 px (`min-h-11`);
- фильтры-переключатели помечаются `aria-pressed`;
- фокус не убирать, не заменять `outline-none` без замены.

**Заголовок страницы.** Новая страница вызывает `useDocumentTitle(title, description)`
— из-за HashRouter иначе все страницы называются одинаково.

## Что уже исправлено — не возвращать обратно

- фото товаров грузились с чужого домена и не открывались → теперь
  `ProductImage` с локальным путём и заглушкой;
- три почти одинаковых компонента хлебных крошек → один `Breadcrumbs trail={[…]}`;
- цены форматировались разбором строки прайса → `formatPrice(priceRub)` в `siteData.js`;
- в подвале стоял выдуманный БИН → `COMPANY_DETAILS`, пустые поля не выводятся.
