# QAZAQTEST — сайт поставщика лабораторного оборудования

React 19 + Vite + Tailwind CSS 4, маршрутизация на HashRouter. Каталог
испытательного оборудования для дорожных и строительных лабораторий Казахстана:
135 позиций, 12 разделов, 27 подразделов, форма заявки с отправкой на внешний
обработчик и запасным вариантом через WhatsApp.

## Команды

```bash
npm install
npm run dev              # http://localhost:5173
npm run catalog:build    # пересобрать src/data/catalog.json из выгрузки
npm run images:download  # скачать фото товаров в public/products/
npm run lint
npm run build
```

## Специализированные агенты

- **catalog-editor** — товары, разделы, описания, характеристики, цены, фото.
- **site-developer** — страницы, компоненты, вёрстка, доступность, SEO.

Правила каждого — в `.claude/agents/`. Прочитай нужный файл перед работой в его
зоне: там описан контракт данных и то, чего делать нельзя.

## Каталог: откуда берутся карточки

```
экспорт WooCommerce (CSV) из админки rutestin.com
        ↓ scripts/import_woocommerce_csv.mjs
src/data/catalog.generated.json  сырая выгрузка (не редактировать)
        ↓ scripts/normalize_catalog.mjs  +  src/data/catalog.overrides.json
src/data/catalog.json            витрина, её импортирует сайт (не редактировать)
```

`catalog.json` перезаписывается целиком при `npm run catalog:build`. Правки
вносятся правилом в скрипте (системная проблема) или записью в
`catalog.overrides.json` (частный случай).

**Ключ overrides — `wp-<id записи в WooCommerce>`**, а не порядковый `qzt-N`:
импорт присваивает порядковые номера заново, а идентификатор записи в магазине
между выгрузками не меняется. Ключ, не совпавший ни с одной позицией, печатается
при сборке — правка не теряется молча.

Что делает нормализация: собирает аннотацию из целых предложений вместо
обрезанных на «…» строк, разбирает характеристики в пары «параметр — значение»,
отделяет маркированные списки от прозы, вытаскивает код модели и бренд,
дописывает код модели к повторяющимся названиям, чистит артефакты Excel,
переводит цену в число.

## Цены

В выгрузке цены в рублях (`priceRub`). Сайт показывает тенге:
`formatPrice()` в `src/data/siteData.js` умножает на `RUB_TO_KZT` и округляет до
1000 ₸. Курс и наценка задаются там же. Позиция без цены выводится как
«Цена по запросу» — придумывать цену нельзя.

## Фото товаров

Фотографий в репозитории нет: исходная выгрузка ссылалась на сторонний сайт,
который недоступен. Пока фото нет, `ProductImage` рисует осмысленную заглушку с
кодом модели. Когда появятся снимки — класть в `public/products/` и проставлять
`image` (или запустить `npm run images:download`, если исходные адреса живы).

## Проверка изменений

```bash
npm run lint && npm run build
```

Визуальная проверка (в репозитории Chromium уже стоит):

```bash
npm run dev &
npx playwright screenshot --browser chromium \
  "http://localhost:5173/#/catalog/general-lab" /tmp/check.png
```

Ключевые адреса: `/#/`, `/#/catalog`, `/#/catalog/asphalt`,
`/#/catalog/asphalt/<slug>`, `/#/contact`.

## Чего не делать

- Не ссылаться на сторонние каталоги и не подгружать оттуда картинки.
- Не выдумывать характеристики, сроки, гарантии, реквизиты и БИН.
- Не редактировать `catalog.json` и `catalog.generated.json` руками.
- Не заводить новые цвета мимо CSS-переменных из `src/index.css`.
